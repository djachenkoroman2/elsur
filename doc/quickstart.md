# Быстрый старт

Пять минут от клонирования репозитория до первого расчёта.

## Что это за система

**survivability** — приложение для оценки живучести (способности выполнять
функции при деструктивных воздействиях) узлов и сетей компьютерных систем.
Оно считает вероятность того, что узел или сеть останутся работоспособными
через заданный период при потоках атак (DDoS, целевые кибератаки, разрывы
каналов), и выбирает рациональный способ защиты в рамках бюджета.
Работает двумя способами: из консоли (пакетный расчёт, скрипты) и через
графический редактор топологии (PyQt) с сохранением проектов в JSON.

Подробности: [user-guide.md](user-guide.md) — для пользователей,
[developer-guide.md](developer-guide.md) — для разработчиков,
[formulas.pdf](formulas.pdf) — аналитические формулы.

## Установка

Требуется Python 3.11+. Внешних зависимостей для консоли нет; GUI требует
PyQt6 (ставится из `requirements.txt`).

```bash
# Windows (Git Bash / cmd):
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

# Linux/macOS:
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Если для вашей версии Python нет колёс PyQt6, установите PySide6
(API-совместимую замену) — код работает с обоими пакетами.

## Первый запуск (консоль)

```bash
# Windows:
.venv\Scripts\python.exe -m survivability --demo
# Linux/macOS:
.venv/bin/python -m survivability --demo
```

`--demo` считает встроенный пример «Узел ЦОИ-1» и печатает отчёт:
общую интенсивность ущерба, вклады каждой угрозы в процентах, живучесть
$Q_i$ и коэффициент готовности $K$.

Следующий шаг — расчёт системы из файла:

```bash
.venv\Scripts\python.exe -m survivability --file examples/example6_system_line.json
```

В отчёте: живучесть системы $Q(S)$, способ расчёта и таблица важности узлов
(критичность Бирнбаума). Файл с ключом `protection`
(`examples/example8_variants_chain.json`) дополнительно сравнивает варианты
защиты и выбирает рациональный $g^*$.

## Первый запуск (графический интерфейс)

```bash
.venv\Scripts\python.exe -m survivability.gui
```

Откроется главное окно: слева редактор узлов/системы/защиты, справа канвас
топологии и панель результатов. Минимальный сценарий: «Узлы → Добавить узел»
(выберите роль, например «Сервер»), расставьте узлы на канвасе мышью,
соедините кнопкой «Добавить связь», затем «Расчёт → Рассчитать Q(S)» (F5).
Пошаговое описание всех элементов — в [user-guide.md](user-guide.md).

## Проверка, что всё работает

```bash
# Windows:
.venv\Scripts\python.exe -m unittest discover -s tests -v
# Linux/macOS:
.venv/bin/python -m unittest discover -s tests -v
```

Должно быть: **123 теста, все OK** (15 GUI-тестов пропускаются, если PyQt
не установлен). Если тесты зелёные — установка корректна.
