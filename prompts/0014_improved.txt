# Задание: подготовить текст научной публикации по проекту survivability

## Контекст

Проект — приложение `survivability` (Python, `F:\dev\elsur`) для количественной
оценки живучести узла и системы компьютерной сети в условиях деструктивных
воздействий (собственные отказы, атаки, разрывы каналов). Реализованы три
задачи формальной постановки:

- **задача 1** — живучесть узла $Q_i$ по марковской модели «отказ–восстановление»
  (`survivability/calc.py`);
- **задача 2** — живучесть системы $Q(S) = P(W(X) \geq W_{\text{доп}})$:
  точный перебор при $n \leq 20$, Монте-Карло с доверительным интервалом
  Уилсона при $n > 20$, важность узлов (`survivability/system_calc.py`);
- **задача 3** — выбор рационального способа защиты
  $g^* = \arg\max_{g \in G} Q_g(S)$ при $C(g) \leq C_{\text{доп}}$
  (`survivability/protection.py`).

Есть графическая оболочка PyQt (`survivability/gui.py`) — редактор топологии,
расчёт, экспорт SVG/DOT. Источники материалов для публикации:

- вывод формул — `doc/formulas.tex` / `doc/formulas.pdf` (полный вывод:
  постановка, модель воздействий, марковская модель, $Q_i$, $Q(S)$, перебор,
  Монте-Карло, важность узлов, выбор защиты, расшифровка обозначений);
- расчёт $Q(S)$ с учётом топологии — `doc/system_topology.md`;
- блок-схемы алгоритмов — `doc/algorithm.svg` (узел), `doc/algorithm_system.svg`
  (система и выбор защиты), архитектура — `doc/architecture.svg`;
- применимость методики к типам узлов — `doc/node_types.md`;
- практическое применение и эффект внедрения — `doc/answ0001.md`;
- примеры входных данных — `examples/example*.json` (узел 1–5, система 6–7,
  защита 8–9); 73+ модульных теста.

## Требования

### 1. Выходной файл и формат

- Текст публикации — в `doc/article.md` с LaTeX-фрагментами
  формулвыполни .
- Статья на русском языке; добавить аннотацию (10–15 строк) и 5–7 ключевых
  слов (RU и EN).

### 2. Структура — строго IMRAD

1. **Введение (Introduction)**: актуальность оценки живучести сетей при
   деструктивных воздействиях; краткий обзор подходов; пробел, который закрывает
   работа; цель и новизна (единый программный инструмент: узел → система →
   выбор защиты, графическая оболочка, воспроизводимость Монте-Карло).
2. **Методы (Methods)**: постановка задач 1–3; марковская модель
   «отказ–восстановление»; функция эффективности $W(X)$ и порог
   $W_{\text{доп}}$; алгоритмы (точный перебор, Монте-Карло с ДИ Уилсона,
   перебор вариантов защиты с бюджетом); архитектура ПО.
3. **Результаты (Results)**: численные примеры на данных из `examples/`
   (таблицы: исходные данные, $Q_i$, $Q(S)$, важность узлов, сравнение вариантов
   защиты, $g^*$); сопоставление точного перебора и Монте-Карло; анализ
   времени работы.
4. **Обсуждение и заключение (Discussion / Conclusion)**: интерпретация
   результатов, ограничения методики (например, порог $n \leq 20$ для перебора),
   направления развития; однозначные выводы по цели работы.

### 3. Формулы

- Все ключевые формулы — в LaTeX, нумерованные, с расшифровкой каждого
  обозначения при первом появлении; обозначения — единообразные по всему тексту
  (сверить с `doc/formulas.tex`, раздел «Расшифровка обозначений»).
- Обязательный минимум: $Q_i$ (случаи $\mu = 0$ и $\mu > 0$), вклады источников
  ущерба, $W(X)$, $Q(S)$, доверительный интервал Уилсона, важность узлов $I_i$,
  задача выбора $g^*$.

### 4. Иллюстрации

- Примеры интерфейса — 2–3 скриншота GUI (редактор топологии, панель
  результатов) или, если скриншоты недоступны, схематичные макеты по
  `doc/gui_layout.svg`.
- Таблицы — с номерами и подписями, формат booktabs.

### 5. Примеры и выводы

- Каждый численный пример сопроводить: исходными данными (в тексте или
  таблице), результатом, интерпретацией.
- Выводы в заключении — только на основании приведённых результатов,
  без неподтверждённых утверждений.

### 6. Список литературы

- Не менее 8–10 реальных, проверяемых источников (книги по надёжности и
  марковским моделям, работы по живучести/отказоустойчивости сетей, метод

- Оформление — по ГОСТ Р 7.0.5 (или IEEE, указать какой стиль выбран);
  список оформляется средствами LaTeX (`thebibliography` или biblatex).
- На каждый источник — хотя бы одна ссылка в тексте (`\cite{...}` / [n]);
